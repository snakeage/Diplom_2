# Diplom2

## Описание
Проект содержит автотесты для API Stellar Burgers. Тесты проверяют функциональность эндпоинтов для создания пользователя, авторизации и создания заказа, согласно предоставленной документации.

## Технологии
- Java 11
- JUnit 4
- REST Assured
- Allure
- Maven

## Структура проекта
- `config`: Настройки REST Assured (`RestConfig`).
- `model`: POJO-классы для сериализации/десериализации JSON.
- `steps`: Логика API-запросов (`ApiSteps`).
- `tests`: Тестовые классы, наследующиеся от `BaseTest`.

## Allure
команда mvn allure:serve для создания отчета
